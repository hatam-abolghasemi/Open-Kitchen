# Contributing

- Ideas and debates: [Discussions](https://github.com/hatam-abolghasemi/open-kitchen/discussions).
- Problems: open an issue.
- Fixes: open a pull request.

Keep the language plain. Behavior changes go in [CHANGELOG.md](CHANGELOG.md).

## Versioning

- **Major:** a core rule changes.
- **Minor:** something new and optional.
- **Patch:** wording only.
